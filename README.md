# Portafolio — José Luis Hidalgo

Sitio web personal / portafolio construido sobre la plantilla **[Massively](https://html5up.net/massively)** de HTML5 UP, personalizado con información de experiencia, educación y habilidades.

🔗 **Demo en vivo:** https://TU-USUARIO.github.io/ *(actualiza este link cuando publiques con GitHub Pages)*

## Contenido

- `index.html` — página principal (Inicio, Sobre mí, Habilidades, Experiencia, Educación, Contacto)
- `assets/` — CSS, JS y fuentes de la plantilla
- `images/` — imágenes usadas en el sitio
- `resume/` — CV descargable en PDF

## Cómo publicarlo con GitHub Pages

1. Crea un repositorio en GitHub (puede llamarse `portafolio` o `TU-USUARIO.github.io` para que se publique en la raíz de tu dominio de GitHub Pages).
2. Sube este proyecto:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/NOMBRE-REPO.git
   git branch -M main
   git push -u origin main
   ```
3. En GitHub, ve a **Settings → Pages**.
4. En "Source", selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda. Tu sitio estará disponible en unos minutos en la URL que GitHub te indique.
